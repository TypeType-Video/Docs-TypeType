# 选择你的算法

::: warning 实验性功能
这里介绍的算法处于 0.0.1 版本。它们展示的内容、设置项和名称都还可能变化。只有当实例的运营者安装并开启了推荐服务，这个页面才会出现。
:::

TypeType 可以用一个由你选择、可以阅读、可以调整的算法来生成你的首页。它会说明读取了你的哪些数据，首页上的每一行都会说明出现的原因，它对你做出的推断也会展示给你，并且可以更正。

变化的只有首页。搜索、订阅和历史记录都保持不变。

算法的名称在界面中以英文显示。

## 开启 {#turn-on}

1. 在菜单中打开 **算法**。
2. 在 **算法首页** 下，开启 **用我选择的算法生成我的首页**。
3. 在 **首页算法** 下选择一个。如果拿不定主意，打开 **哪种算法适合我？**：那里会把它们并排比较。
4. 回到首页。

第一个页面可能需要几秒钟。在此期间你看到的是平常的首页，并带有“你的首页正在出锅”的提示；新页面会自动替换它。

如果菜单里没有 **算法**，说明你的实例没有提供这项功能。在某些实例上，管理员已为所有人开启：这时选项已经是开启状态，你可以把它关掉。

对于空账号，首页会显示一张欢迎卡片，上面有两个按钮：**导入我的数据** 和 **选择我的算法**。在你导入数据或观看几个视频之前，算法没有可以依据的内容。

## 各种算法 {#algorithms}

没有标准答案，只有不同的观看方式。

| 算法 | 你会看到什么 | 读取的数据 |
| --- | --- | --- |
| Subscriptions | 你关注的频道的最新视频，按发布时间排列：今天、最近七天、更早。不会对你做任何推断。 | 订阅 |
| Discovery | 订阅频道的新视频、与它们以及与你的收藏相关的、来自你未关注频道的视频，还有热门视频。 | 订阅和收藏。从不读取你的历史记录。 |
| Signals | 你没看完的视频、你看过的创作者的更多视频、按话题分的行，以及一行你从未看过的创作者。它会在几分钟内对你刚看过的内容做出反应。 | 视频历史、收藏、订阅 |
| Signals, channels | 你看得最多的创作者以及你订阅频道的最新视频。 | 视频历史、收藏、订阅 |
| Signals, videos | 你所看内容的主题，不论视频出自谁。 | 视频历史、收藏 |
| Signals, mix | 你看的创作者，以及任何创作者关于你感兴趣主题的视频。 | 视频历史、收藏、订阅 |

在指南中，每种算法都带有三个刻度，从无到高：

- **个性化**：首页在多大程度上取决于你看的内容。
- **发现**：给你还不认识的频道留了多少位置。
- **多样性**：每次刷新时页面变化有多大。

每种算法还会读取你标记为 **不适合我** 的内容，以便把它们排除；除 Subscriptions 外，其他算法都会读取最近在你首页上展示过的内容，以免重复。

算法只会收到它在 **使用的数据** 下列出的数据。不读取历史记录的算法永远收不到你的历史记录。

你可以随时切换。你的数据和每种算法的设置都会保留。

## 算法页面，逐节说明 {#page}

### 概览

两张图表：你的首页由什么组成（未看完的视频、最近观看、订阅、你的兴趣、新创作者、热门），以及你每个兴趣所占的比例。每一部分都能跳转到对应的设置位置。

### 使用的数据 {#data}

为你的账号保存的全部内容，按类别列出：视频历史、Shorts 历史、收藏、订阅、搜索历史等。蓝色表示当前算法读取的内容，灰色表示保留但不用于首页的内容。

打开某个类别可以设置：

- **收集**：关闭后，这个类别不再记录新内容。已有的内容保留。
- **用于首页**：关闭后，这些条目仍然保存，但任何算法都不会读取。
- **回看范围**：算法往回读取多久，从几天到不限。更早的条目仍在你的账号中，只是不再计入首页。
- 对单个条目 **排除**：该条目保留，但永不读取。**包含** 可以把它放回去。

这些选择都不会删除任何东西。

### 它保留了什么 {#profile}

算法从你的数据中推断出的内容。在你观看几个视频之前，这里是空的。

- **兴趣。** 每个兴趣以其视频标题中共有的词命名，并显示它依据了多少个条目，同时列出你自己的几个视频。对每个兴趣可以：
  - **置顶**：它在首页上始终有一行；
  - **隐藏**：它不再出现在首页上；
  - **不计入**：它不再算作兴趣，但其中的视频仍可能出现。
- **添加** 一个主题，用你自己的话、任何语言都可以（“天文”“日本料理”）。算法随后会查找相关视频。
- **观看最多的频道。** 选中一个可以查看它的依据，或者让它不再计入。
- **最近观看。** 不久前看过、仍在影响首页的视频，每个都标有还会计入多少分钟。**忘记** 会去除它的影响，但不会清除你的历史记录。

兴趣是按标题的含义找出来的，任何语言都适用：同一主题下，一个阿拉伯语标题的视频和一个英语标题的视频会归到一起。

修改会在下次刷新首页时生效。

### 详情 {#details}

**全部设置** 按类别列出所选算法的每一项设置：

| 类别 | 设置的内容 |
| --- | --- |
| 来源 | 算法从哪里寻找候选视频 |
| 权重 | 给候选视频排序时最看重什么 |
| 近期视频 | 看过的视频对首页的影响持续多久 |
| 页面 | 页面的大小以及如何分配 |
| 发现 | 给你还没看过的内容留多少位置 |
| 随机性 | 首页是否每次刷新都变化 |

每项设置都显示默认值和一个 **恢复** 按钮，**恢复默认设置** 会把全部设置还原。关闭随机性后，相同的数据总会得到相同的页面。

**上一次首页是如何生成的** 针对你刚看到的页面显示：找到了多少视频、来自哪些来源，有多少被搁置以及原因（已经看过、已屏蔽、已隐藏的兴趣、同一频道过多、来自已排除的数据、Shorts），各行及其原因，以及得分最高的视频和得分的构成。这些内容来自生成该页面的同一次计算。

如果它提示还没有由算法生成过首页，请先打开首页。

**源代码** 链接到所选算法的代码。

### 我的意见 {#opinions}

你对首页给出的意见，每条都有一个 **撤回** 按钮。只保存你选择发送的内容，以及你当时使用的算法和设置。它会随你的导出一并带走。

## 在首页上 {#home}

- **行与原因。** 在 **首页布局** 下选择 **照常**（一个网格）或 **按类别**（每个原因一行并带标题）。两种方式下视频是相同的。
- **不适合我。** 在卡片上点 **不适合我** 会立即移除该视频。在 **为什么？（可选）** 下可以回答 **已经看过**、**不要这个频道**、**不要这个话题** 或 **其他**。**撤销** 可以把卡片放回来。选择 **不要这个话题** 后，卡片会提供隐藏该主题的选项；被隐藏的主题可以在 **它保留了什么** 中找回。
- **这个页面合你心意吗？** 回答 **好** 或 **不好**，愿意的话还可以说明问题：太重复、与你无关、旧视频太多、缺少你的频道。如果你不回答，什么都不会发送。

## 关闭 {#turn-off}

关闭 **用我选择的算法生成我的首页**。你会立刻回到平常的首页。你的选择、更正和意见都会保留，以便你再回来。
