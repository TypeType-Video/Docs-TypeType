# 设置

调整 TypeType 为你工作的方式。这里的一切都按账号保存，并存放在你的实例上。

![设置页面](/screenshot-settings.png)

## 播放 {#playback}

- **自动播放下一个视频**：一个视频结束时自动开始下一个。
- **默认画质**：视频打开时使用的分辨率。
- **启用高画质播放**：在可用时允许更高画质的视频流。

在所有受支持的浏览器上，YouTube 播放都使用有状态的 SABR 路径。NicoNico 和 BiliBili 保留各自提供方专用的播放路径。

## 字幕 {#captions}

自定义字幕的外观：大小、颜色和背景，让字幕按你喜欢的方式保持清晰易读。

## 语言 {#languages}

- **音轨偏好**：视频有多条音轨时自动选择的音频语言。
- **强制使用原始语言**：保留原始音频，而不是配音音轨。

## SponsorBlock {#sponsorblock}

决定如何处理社区标记的片段：

- **行为**：自动**跳过**，在进度条上**标记**但不跳过，或者**关**以完全忽略 SponsorBlock。
- **类别**：选择哪些类型的片段计入（赞助、自我推广等），每种可设为跳过 / 标记 / 隐藏。
- **更细的控制**：显示章节、在时间旁显示当前片段、用静音代替跳过、对整段视频标签手动跳过，以及仅在音乐视频中跳过非音乐部分。

![SponsorBlock 的类别与控制项](/screenshot-sponsorblock.png)

## 你看到的内容 {#what-you-see}

调整各个界面：

- 在主页上**隐藏未看完的视频**。
- 在主页上**隐藏个性化推荐**。
- **选择生成首页的算法**（在实例提供该功能时）。见[选择你的算法](./algorithm)。
- 在观看页面上**隐藏推荐栏**。
- **隐藏短视频**的导航入口并屏蔽短视频页面。
- **评论和弹幕**：显示或隐藏。
- **默认着陆页**：打开时进入主页、订阅或其他页面。

![内容开关：什么显示在哪里](/screenshot-content-toggles.png)

## 服务 {#service}

选择当前服务，**YouTube、NicoNico 或 BiliBili**，让搜索和浏览指向正确的来源。

## 关于 {#about}

“关于”一节显示网页应用、Server、Token 和 Downloader 报告的版本、完整修订号和构建时间。每个组件都单独检查，所以某个内部服务不可用时，不会影响其他组件返回的版本信息。更新之后，用刷新按钮获取当前的值。
