# 你的媒体库

你保存的一切都在你的实例上、你的账号里，而不是在第三方那里。

## 订阅 {#subscriptions}

订阅频道后，你的 **订阅** 信息流会把它们的最新视频集中在一处。你可以在[设置](./settings#what-you-see)中把订阅设为默认着陆页，也可以在[隐私与屏蔽](./privacy)中一次性取消所有订阅。

预定的直播按其预定时间排列。当一个直播从预定变为正在直播时，在第一次观察到这一变化时会被提升一次，之后随着更新的视频到来，它会回到按时间顺序的位置。这样，长期进行的 24/7 直播就不会一直排在最近的视频上方。

![你的订阅信息流](/screenshot-subscriptions.png)

## 播放列表 {#playlists}

创建并管理你自己的播放列表：

- 用 **新建播放列表** **创建**一个，并给它起个名字。
- 用 **添加到播放列表** **添加**视频，在观看页面以及主页、订阅和相关视频的卡片上都可以使用。
- 通过拖动**重新排序**，或者**随机播放**。
- **移除**某个视频，或**删除**整个播放列表。

你还可以把其他人的**公开播放列表保存**到自己的媒体库，用完之后再把保存的播放列表移除。

![你的播放列表](/screenshot-playlists.png)

## 历史 {#history}

你的**观看历史**记录你看过的内容，并从上次停下的地方继续播放。你可以随时清除它，见[隐私与屏蔽](./privacy#your-data)。

![你的观看历史](/screenshot-history.png)

## 稍后再看 {#watch-later}

把视频放进 **稍后再看**，以后再回来看：这是一个独立于播放列表的简单队列。打开视频的操作菜单并选择 **添加到稍后再看** 即可立刻加入；在同一个菜单中选择 **从稍后再看中移除** 即可移除。

## 收藏 {#favorites}

把视频标记为 **收藏**，方便以后快速找到。
