# 用户指南

TypeType 运行起来、你登录之后，实际能做些什么。

TypeType 是一个完整的、可以自托管的 **生态**，面向 **YouTube、NicoNico 和 BiliBili**：你自己的账号、媒体库和播放器，背后是你自己的 API 服务器、下载器和登录服务，全部运行在你的实例上。

![运行在自托管实例上的 TypeType](/screenshot-home.png)

## 一览 {#at-a-glance}

- **观看** YouTube、NicoNico 和 BiliBili 的内容，都在一个地方，配有真正的播放器、画质和倍速控制、影院模式、原生画中画、字幕、音轨、SponsorBlock 和逐帧步进。见[观看与播放器](./watching)。
- **建立媒体库**：订阅、播放列表、历史、稍后再看和收藏，都留在你的实例上。见[你的媒体库](./library)。
- **查找内容**：搜索、频道、短视频、播客和主页信息流。见[查找内容](./finding-content)。
- **登录**：使用本地账号或单点登录（OIDC）。见[登录](./accounts)。
- **按自己的习惯调整**：播放默认值、语言、字幕、SponsorBlock，以及显示哪些界面。见[设置](./settings)。
- **保持掌控**：清除历史记录、屏蔽频道、管理你的数据。见[隐私与屏蔽](./privacy)。
- **选择生成首页的算法**（在实例提供该功能时）。见[选择你的算法](./algorithm)。

## 把你的数据带进来 {#bringing-your-data-in}

已经在别处有订阅和播放列表了？你可以从 Google Takeout 导出文件或 PipePipe 备份中导入，见[导入你的数据](/zh/self-hosting/importing-data)。

## 第一次来？ {#first-time-here}

如果你还没有搭建实例，请从[自托管指南](/zh/self-hosting/introduction)开始。本用户指南假定你已经有一个实例和一个账号。
