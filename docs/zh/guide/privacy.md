# 隐私与屏蔽

TypeType 把你的数据保存在你自己的实例上，并提供管理这些数据的控制项。

![管理你保存的数据](/screenshot-privacy.png)

## 屏蔽频道 {#blocking-channels}

屏蔽一个频道后，它的视频不会再出现在你的信息流、主页、搜索、相关视频以及其他任何地方。在设置中管理你屏蔽的频道，随时可以解除对任何一个的屏蔽。

## 你的数据 {#your-data}

保存什么由你掌控：

- **清除观看历史**。
- **清除搜索历史**。
- 一次性**取消订阅所有频道**。

这些操作立即生效且无法撤销，所以应用会先请你确认。

## 保存了什么 {#what-is-stored}

你的账号保存你的订阅、播放列表、历史记录、稍后再看、收藏和设置，仅此而已，而且全部在你（或你的管理员）运行的实例上。不会与任何第三方共享。
